# ÉLAN — Atlas de movimentos (estudo)
Curadoria comparativa de 38 mecanismos de animação, com comentários técnicos e quadros reduzidos de revisão.
As demonstrações e fotografias originais são obras dos respectivos autores e aparecem aqui apenas para análise, com links às fontes.
Não é site oficial, não é página comercial, nem versão aprovada da marca.
